اتصال به Google Sheets

با اتصال، هر ثبت روی گوشی خودکار به گوگل شیت شما فرستاده می‌شود و عکس فاکتورها در گوگل درایو ذخیره می‌شوند. بدون اینترنت هم ثبت کنید؛ بعدا خودش می‌فرستد.

راهنمای اتصال (یک بار، حدود ۵ دقیقه)
  1. در گوگل درایو یک Google Sheet خالی بسازید (مثلا با نام «تنخواه»).
  2. از منوی Extensions گزینه Apps Script را بزنید، هر چه نوشته شده پاک کنید و محتوای فایل Code.gs را بچسبانید.
  3. در خط const TOKEN = 'CHANGE-ME-1234'; یک رمز دلخواه با حروف و عدد انگلیسی بنویسید و ذخیره کنید.
  4. از بالای صفحه تابع setup را انتخاب و Run کنید. اجازه‌ها را تأیید کنید (Advanced ← Go to … ← Allow).
  5. Deploy ← New deployment ← نوع Web app؛ Execute as: Me و Who has access: Anyone ← Deploy.
  6. آدرس Web app (که به /exec ختم می‌شود) و همان رمز را اینجا وارد کنید و «اتصال» را بزنید.

اگر بعدا کد اسکریپت را عوض کردید: Deploy ← Manage deployments ← ویرایش ← Version: New version.
